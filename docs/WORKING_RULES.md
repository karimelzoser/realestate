# Working Rules

1. Keep `main` usable at all times.
2. Use a branch for substantial UI or workflow changes.
3. Do not remove working functionality while redesigning a page.
4. System-map direct previews and role workspaces are different modes.
5. Test every flow-map destination after changing navigation.
6. Test How It Works at 1280x720, 1366x768, 1440x900, 1600x900.
7. Check for overlap, clipping, accidental horizontal page overflow, and unreadable text.
8. Preserve the shared-queue model across online and offline buyers.
9. Preserve atomic exact-unit lock semantics.
10. My Property must remain a functional after-sale area including property details, installments, contract, documents, and updates/support.
11. Keep AI actions permission-aware and require user confirmation for irreversible legal/financial actions.
